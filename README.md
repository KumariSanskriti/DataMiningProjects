# E-Commerce Data Mining Project

This project focuses on analyzing e-commerce transaction data using Python.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Objectives
- Explore and understand e-commerce transaction data.
- Clean missing and duplicate records.
- Analyze sales and revenue.
- Identify top-selling products.
- Perform customer and country-wise analysis.

## Dataset
Online Retail / E-Commerce Transaction Dataset from Kaggle.
